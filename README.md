## Описание программы
*"Weather Diary — это консольное приложение для ведения дневника погоды. Позволяет
добавлять записи о температуре, осадках, фильтровать их по дате и строить графики
температуры."*
---
## Требования для запуска
Что нужно установить на компьютер:
- Python 3.10 или выше
- Библиотеки: `pip install matplotlib requests`
---
Как пользоваться
1. При запуске появляется меню:
2. text
1 — Добавить запись
2 — Показать все записи
3 — Фильтровать по дате
3. 4 — Выйти
4. Выбери нужный пункт, введи данные.
5. Данные автоматически сохраняются в weather_data.json

Пример работы

Добавление записи:
Введите дату (ГГГГ-ММ-ДД): 2026-05-15
Введите температуру: 22.5
Введите описание: Солнечно
Осадки (да/нет): нет
✅ Запись добавлена!

Фильтрация по температуре > 10°C:
2026-05-15 | 22.5°C | Солнечно | Нет осадков
2026-05-14 | 21.0°C | Облачно | Нет осадков
